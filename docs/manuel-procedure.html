0. Objet, acteurs, règles générales

0.1 Objet

Décrire, pas à pas, qui fait quoi, dans quel écran et avec quelle preuve, pour les deux activités : livraison de colis à moto (distribution.html, livreur.html, vendeur.html, portail.html) et gestion du parc de taxis (transport.html).

0.3 Règles générales (tous acteurs)

  1. Identifiants personnels : jamais de partage de mot de passe ou PIN. Blocage après 5 échecs (60 s côté hub) ; réinitialisation par l'administrateur.
  2. Droits : chacun ne voit et ne fait que ce que son rôle autorise. Personne ne valide ce qu'il a saisi.
  3. Journal d'audit : toute action sensible (annulation, validation, correction, planification) est tracée. Tout motif demandé est obligatoire.
  4. Application installable : Android/Chrome « Installer l'application » ; iPhone Safari → Partager → Sur l'écran d'accueil. Hors ligne : les actions du livreur restent en file et repartent seules.
  5. Argent : tout encaissement est enregistré le jour même, avec référence pour Mobile Money / virement. Aucun justificatif, aucune dépense au-dessus du seuil.
  6. Sauvegarde : l'administrateur exporte la sauvegarde signée à la fréquence fixée par la direction et teste la restauration.

A. LIVRAISON

Commande reçue → Confirmée → Préparation → Prête → En livraison → Livrée (issues : échec, retour, annulée)

A2. Collecte chez un vendeur partenaire

Commandes de vendeurs partenaires uniquement. Procédure détaillée : docs/MANUEL_COLLECTE.pdf.

Planifiée → Acceptée → En route → Collectée → Réceptionnée
  1. Superviseur : Centre de livraison → Collectes → Planifier ; choisir commandes, livreur, créneau, adresse ; la collecte reçoit un numéro COL-AAAA-NNNN et un code à 4 chiffres vu du vendeur seul. Imprimer le bon de collecte.
  2. Livreur : Accepter ou « Impossible » (motif obligatoire) ; Je pars ; vérifier les articles avec le vendeur ; le vendeur remet les colis puis donne son code ; saisir code et nombre de colis par commande.
  3. Préparateur : Commandes → Collectes à réceptionner ; compter ; écart ⇒ incident automatique (colis manquant / écart de colis).

A3. Préparation et étiquetage

  1. Préparateur : Démarrer la préparation (désactivé tant qu'une collecte est ouverte pour la commande).
  2. Prélever les articles, contrôler quantités ; le stock décroît ; ajuster par une saisie d'inventaire si écart.
  3. Imprimer les étiquettes QR des colis ; coller sur chaque colis.
  4. Marquer prête. Imprimer le bon de livraison.

A4. Affectation et suivi des livraisons

  1. Superviseur : Centre de livraison → Affecter ; choisir un livreur disponible (courses en cours visibles), dossier complet et valide si l'option est active.
  2. Remise des colis au livreur contre signature / scan des étiquettes.
  3. Suivi : Tour de contrôle et Carte en direct ; alertes de retard, SOS.
  4. Réaffecter si le livreur refuse ou tarde ; motif obligatoire pour toute annulation.

A6. Échecs, retours et incidents

  1. Superviseur : Centre → Échecs et retours ; choisir : reprogrammer (nouvelle date/livreur) ou retour.
  2. Préparateur : Réceptionner le retour ; compter, remettre en stock.
  3. Tout écart ou colis manquant ⇒ incident INC-NNNN ; le superviseur instruit (responsabilité, dédommagement) et clôt avec décision écrite.

A8. Clôture de la journée du centre

  1. Toutes les missions du jour sont terminées, reprogrammées ou en retour.
  2. Versements validés ; tournées clôturées ; écarts traités.
  3. Superviseur : Centre → Clôture ; relire alertes (collectes non planifiées, signatures à vérifier, incidents ouverts).
  4. Caissier : clôture de caisse ; Direction : lit le tableau de bord.

B. GESTION DE TAXI

Véhicule + Chauffeur → Contrat → Échéances journalières → Versement → Reçu → Caisse → Comptabilité

B1. Entrée d'un véhicule dans le parc

  1. Gestionnaire de flotte : Véhicules → Créer : immatriculation, marque, type, année, kilométrage.
  2. Joindre les documents : carte grise, assurance, visite technique, carte de transport (PNG, JPEG, WebP, PDF ≤ 300 Ko). Badge « dossier incomplet » tant qu'il manque une pièce.
  3. Programmer le plan d'entretien préventif (B6) et la pose du boîtier GPS (B8).
  4. Statuts : disponible, en service, immobilisé (maintenance / sinistre), sorti du parc (historique conservé).

B2. Enregistrement d'un chauffeur

  1. Chauffeurs → Créer : identité, téléphone, adresse.
  2. Pièces : photo, permis, carte d'identité ; vérifier la validité du permis.
  3. Créer son compte pour le portail chauffeur (code PIN) ; le remettre en main propre.
  4. Affecter le chauffeur à un véhicule (Affectations) ; l'historique est conservé.

B3. Contrat d'exploitation

ModePrincipe
A — Recette journalièreMontant dû chaque jour d'exploitation ; jour de repos : aucune recette due
B — Location périodiqueLoyer selon périodicité fixée au contrat
  1. Directeur / flotte : Contrats → Nouveau : véhicule, chauffeur, mode, montant, jours de repos, dépôt de garantie, dates.
  2. Imprimer le contrat (9 articles, modèle modifiable) en deux exemplaires ; faire signer ; saisir la date et scanner le contrat signé.
  3. Changement de tarif : avenant (versionné). Changement de mode : procédure dédiée, historique conservé.
  4. Exonération ou journée exceptionnelle : décision du directeur, motif obligatoire.
  5. Le planning et les échéances sont générés ; contrôler le planning chaque semaine.

B4. Versements et reçus

  1. Le chauffeur verse sa recette / son loyer au bureau (espèces, Mobile Money, virement).
  2. Caissier : Encaissements → choisir le chauffeur, l'échéance, le moyen ; Mobile Money / virement : saisir la référence et la vérifier.
  3. Paiement partiel autorisé : imputé sur les plus anciennes échéances. Le système refuse un doublon.
  4. Émettre et remettre le reçu ; le chauffeur le retrouve sur son portail et le confirme.
  5. Erreur : annulation motivée uniquement (jamais de suppression) ; trace dans l'audit.
Relance : arriérés suivis dans Échéances et Rapports (ancienneté des impayés). Rappel WhatsApp au chauffeur avant toute suspension.

B5. Caisse et dépenses

  1. Caissier : ouvrir la caisse (fonds de départ) ; toutes les opérations du jour y passent.
  2. Dépense : saisir catégorie, montant, véhicule concerné ; justificatif obligatoire au-dessus du seuil ; validation par le contrôleur / direction au-dessus du seuil de validation.
  3. Fin de journée : clôturer ; compter ; écart expliqué ; le contrôleur le valide.
  4. Remise en banque : opération « Versement en banque » ; pointage banque par le contrôleur avec le relevé.

B6. Entretien préventif et maintenance

  1. Plan par véhicule en km et en jours : vidange, plaquettes, pneus, batterie, courroie, révision. États : à prévoir / en retard.
  2. Rappel WhatsApp au chauffeur ; programmer le passage au garage dans l'Agenda atelier.
  3. Ouvrir un ordre de maintenance : le véhicule passe immobilisé ; saisir pièces utilisées (stock de pièces, coût moyen pondéré) et main-d'œuvre.
  4. Clore l'ordre : remise en service, consommation des pièces, dépense liée créée (à valider).
  5. Inventaire des pièces : périodique ; seuils d'alerte de réapprovisionnement.

B7. Sinistre

  1. Chauffeur : déclarer l'incident dans le portail (photos, lieu, circonstances) et prévenir le bureau.
  2. Flotte : ouvrir le sinistre ; workflow demande → expertise → réparation → clos ; immobiliser le véhicule.
  3. Déclaration à l'assureur dans le délai du contrat ; joindre PV / constat.
  4. Dépense de réparation liée au sinistre ; décider de la responsabilité du chauffeur (directeur).

B8. Suivi GPS

  • Carte : position, fraîcheur du signal, historique de trajet.
  • Zones autorisées ; alerte de sortie de zone.
  • Boîtier injoignable ou retiré : mise en quarantaine et enquête du gestionnaire de flotte.

B9. Documents et alertes

  1. Contrôleur : lire chaque semaine Documents et alertes : assurance, visite technique, carte de transport, permis arrivant à échéance.
  2. Renouveler avant la date ; scanner la nouvelle pièce.
  3. Traiter les demandes chauffeurs (congé, changement de profil) ; la modification du profil est validée par le bureau.

B10. Portail chauffeur (pour le chauffeur)

BesoinOù
Voir ses reçus et son soldeCompte / Reçus (confirmer chaque reçu)
Voir son véhicule et ses échéancesVéhicule
Déclarer une panne ou un accidentIncident (avec photo)
Demander un congé, un changementDemandes
Modifier ses coordonnéesProfil (validé par le bureau)

B11. Comptabilité et clôture mensuelle (SYSCOHADA)

  1. Comptable : vérifier que tous les encaissements, reçus et dépenses de la période sont comptabilisés (partie double).
  2. Rapprocher caisse, banque et comptes tiers ; lettrer ; corriger par extourne (jamais de suppression).
  3. Éditer balance, grand livre, journaux ; faire valider par le directeur.
  4. Clôturer la période ; les écritures de la période deviennent immuables.
  5. Faire une sauvegarde signée et la ranger hors de l'appareil.

Le plan de comptes est indicatif : à valider par le comptable avant production.

B12. Fin de contrat

  1. Constater les arriérés ; imprimer le décompte de fin (solde dû, retenue sur dépôt, reste à payer ou dépôt à restituer).
  2. Dépôt versé : le rembourser avant résiliation, ou le compenser selon le décompte.
  3. Résilier le contrat (motif) ; récupérer clés et documents ; état des lieux du véhicule.
  4. Véhicule : retour à « disponible » ou maintenance ; chauffeur : désactiver l'accès au portail.
  5. Possibilité de créer un nouveau contrat à partir du contrat résilié.

C. ANNEXES

C1. Règles d'or

  1. Pas de preuve, pas de validation (code vendeur, signature, justificatif, référence).
  2. On ne supprime pas : on annule avec motif, on extourne.
  3. Un encaissement = une écriture le jour même.
  4. Personne ne valide ce qu'il a saisi.
  5. Un document expiré = un véhicule ou un chauffeur à l'arrêt.
  6. Toute anomalie est signalée au responsable dans la journée.
